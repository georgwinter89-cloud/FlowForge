So arbeitet FlowForge

Du baust ein Schaubild aus Blöcken — FlowForge steuert den Lauf und erzwingt die Regeln — ein frischer KI-Agent je Block arbeitet im Projektordner — du siehst, was passiert ist.

2 · FlowForge steuert · 0 Tokens
Die Werkbank erzwingt
  • Ein Auftrag je BlockArbeitspaket, Übergaben der Vorgänger, Vorspann: wer bekommt dein Ergebnis und wozu.
  • Harte Sperren am WerkzeugaufrufGit · Verwaltungsdateien · „darf nur lesen" · fremdes Revier — ein Nein mit Begründung, keine Bitte im Prompt.
  • Rechte-Rückfragen an dichAußerhalb des Projektordners, Internet, Unumkehrbares — in Alltagssprache, oder im Automodus vermerkt.
  • Sicherungspunktevor dem Lauf und nach jedem schreibenden Block — unsichtbares Git, jederzeit zurückholbar.
  • Lieferschein statt FreitextPflichtfelder je Block; fehlt etwas, genau eine Nachforderung — dann hält der Lauf an.
  • Reparatur-Runde bei RotPrüfer-Beanstandungen als Felder + Diff zurück an den Bauer; Tor ohne KI spielt den Prüfbefehl vorher ab.
  • Übertrag bei ~85 % KontextÜbergabe, frische Session, derselbe Block läuft weiter.
3 · Der Motor arbeitet
Claude Code CLI über das Agent SDK
Anmeldung: dein Claude-Abo (Abo-Kontingent) oder API-Schlüssel mit Ausgaben-Obergrenze je Lauf — du wählst beim ersten Start.
Koordinator Haiku — eine Session je Lauf, delegiert nur
Block-Agent — frisch je Block, erbt kein Arbeitsgedächtnis
Standard Opus · sparsam Sonnet · sehr sparsam Haiku — wählbar je Karte
Unteraufgaben: Späher, Einlese-Helfer, Audit-Blickwinkel
Werkzeuge: lesen, schreiben, Befehle, Karten-Werkzeuge, Lieferschein melden — jeder Aufruf geht durch FlowForges Sperren (Spalte 2).
Lokale Helfer-KI (Ollama, optional): Recherche, Entwürfe, Bau-Teilaufträge — kostet kein Kontingent; der Agent nimmt ab, Sicherungspunkt davor.
Projektordner: Code · Karten · Prüfmappe — die Wahrheit liegt auf der Platte, nicht im Chat.
4 · Du siehst
Ehrlich, was passiert ist
  • Live-TickerJeder Werkzeugschritt, jede Sperre, jeder Wartegrund („Prüfer wartet auf Bauer") — Kontext-Füllstand als Balken.
  • LaufberichtBlöcke mit Ausgang, Tokens und Modell, theoretische Kosten, Rechte-Rückfragen, Überträge, Vorschlag fürs nächste Paket.
  • Sicherungspunkte„21:32 — Bauer fertig" — Wiederherstellen mit Vorschau, selbst wieder rückgängig.
  • KartenStatus, Aufgaben, Entscheidungen, Wissen — vom Sessionende gepflegt, von dir bearbeitbar.
  • MetrikenPrüfer besteht beim ersten Mal, Reparatur-Runden je Lauf, Trefferquote der lokalen KI — kein Agent sieht sie.
Du entscheidest bei Rechte-Rückfragen, Folgen-Fragen („was bedeutet das für dich") und im Gespräch mit dem Block „Frage an den Menschen" — sonst läuft der Lauf allein.
